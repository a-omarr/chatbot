# Frontend (React + TypeScript + Tailwind)

## Quick start

```bash
# from project root
cd frontend

# install dependencies
npm install

# start dev server
npm run dev
```

The app will be available at `http://localhost:5173`.

During development, API calls to `/api/...` are proxied to `http://localhost:8000` as configured in `vite.config.ts`.

## Tech stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- ESLint (TS + React)
